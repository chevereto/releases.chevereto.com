# Chevereto 3.15.0

2020-04-16

  • Added automatic importing
  • Added configurable display of embed codes (all, none, users) [11957 (opens new window)]
  • Added file picker workaround for webview (Wechat, QQ) [12033 (opens new window)]
  • Added pup.js support for ProBoards [11927 (opens new window)]
  • Added pup.js support for Quill editor (Vanilla Forums) [11932 (opens new window)]
  • Added rebuild stats button
  • Added tone mode light/dark toggle
  • Fixed bug in "move to album"
  • Fixed bug in API remote URL uploads [12060 (opens new window)]
  • Fixed bug in External Storage S3 API [11917 (opens new window)]
  • Fixed bug in image Exif orientation [11846 (opens new window)]
  • Fixed bug in social signup [12007 (opens new window)]
  • Fixed bug in URL rewriting [11840 (opens new window)]
  • Fixed login when updating prior to 3.14.0
  • Fixed missing "hostname" setting
  • Fixed XSS vulnerability in image uploader [11899 (opens new window)]
  • Improved image upload performance (parallel uploads)
  • Removed CloudFlare, Theme top bar color dashboard settings
  • Updated all vendor dependencies
  • Updated Bulgarian, Chinese Simplified, Chinese Traditional, Czech, Danish, Dutch, Estonian, German, Indonesian, Italian, Japanese, Korean, Lithuanian, Spanish and Turkish translations
