# Release 4.X

Chevereto V4 is a major quality leap, a complete modernization of Chevereto with updated coding standards and better application architecture. Everything driven by our own-made Chevere (opens new window) framework.

This release adds custom semantics, call to action buttons, user-based api, theme palettes, faster rendering, keyboard shortcuts, CSAM protection, folder upload, two-factor auth, xrDebug support, improved console, REPL, web share API, routing settings, encrypted secrets, image delete link, one-click system update, video support, configurable view for user profiles, customizable theme font, tagging system, improved storage management, AVIF image format support, system performance improvements, refined user interface and mobile experience, expanded content listing in explore, application-level cache, chunked uploads, lossless JPEG handling, support for GoPro 360 photos, Cloudflare Turnstile captcha and first-class multi-tenancy.
